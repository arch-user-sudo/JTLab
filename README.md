*This bar uses the wbg wallpaper tool found at https://codeberg.org/dnkl/wbg.git to set the wallpaper. 
*this bar uses wlsunset for its bluelight filter. 
*Please dont forget to set your wallpaper directory in the config.h and disable or stop any other wallpaper tools that are running as this bar handles that for you.
*Bind "jtlabctl menu" to a key as a short cut to open the app launcher using the keyboard
*NB This bar does not play well with blur
